# fwms-pages — بوابة الواجهة العامة على Cloudflare Pages

> **ملكية المساعد الأول** (`infra/cloudflare/**` — COORDINATION §3).
> أنشئت بطلب صاحب المشروع الصريح (2026-10-18): «يجب نشر فرونت أند المنصة على Cloudflare: fwms.pages.dev».

## ما هذا؟

مشروع Cloudflare Pages باسم **`fwms`** يعرض منصة FWMS كاملة (الواجهة + الـ API) عبر بوابة عكسية
(Pages Advanced Mode: `_worker.js` يعالج كل الطلبات) إلى **أصل Node سليم** — نفس نمط البوابة القائمة
`fwms-proxy` (التي تعرض خادم الهاتف) لكن بأصل سحابي دائم التاح.

**لماذا بوابة وليس تشغيل التطبيق مباشرة على Pages؟** التطبيق يعتمد حصرًا على Node APIs لا يوفرها
workerd: Prisma + SQLite بملف محلي، bcrypt، sharp، وعملية العرض الابنة (render-worker). تشغيله على
Pages يتطلب إعادة كتابة جذرية تكسر المكتسبات — البوابة تحفظ «كود واحد وسلوك واحد» (SPEC §7).

## العنوان العام

- النطاق المُسند من Cloudflare: **`fwms-dg8.pages.dev`**
- طلب المالك الأصلي كان `fwms.pages.dev` — **محجوز عالميًا لدى طرف ثالث** (موقع تايلاندي `lang="th"`
  قائم قبل الإنشاء؛ مجال `*.pages.dev` حجزٌ إقليمي أولويّ أولًا). حاولنا المطالبة عبر
  `PATCH subdomain=fwms` فتجاهلها النظام (النطاق غير متاح). المشروع **اسمه** `fwms` كما طُلب.
- **للحصول على عنوان أنظف لاحقًا:** أضف نطاقًا مخصصًا (Custom Domain) للمشروع من لوحة Cloudflare —
  يعمل مباشرة فوق البوابة بلا أي تغيير في الكود.

## الأصل (Origin policy)

| الأصل الحالي | السبب |
|---|---|
| `https://fwms.tarikc.workers.dev` | **بوابة الهاتف (الخادم المرجعي) عبر النفق** — محدَّث 2026-10-23 بأمر المالك وتوكن الحساب. سبب التبديل (مقيس): نشر Vercel يعمل على لقطة SQLite مؤقتة في `/tmp` تُنشأ لكل نسخة، فالوثائق المولَّدة عليه تضيع (تنزيل/نسخة محدَّثة يفشلان) ومسح QR يعطي `not_found` مع أن الرابط يعمل. النتيجة: الرابط المطبوع على الوثائق (pages.dev) يخدم بيانات الإنتاج مباشرةً. **الشروط:** الهاتف ≥ v0.9.2 (هو الآن v0.12.1) والنفق قائم — وإن غاب النفق تعيد البوابة 503. |

**سجل التبديل:** كان الأصل `https://fwms-orpin.vercel.app` (نشر تلقائي من `main`، لقطة معاينة) حتى 2026-10-23؛ ثم نُفِّذ التبديل بعد تأكيد `curl https://fwms.tarikc.workers.dev/api/health` ⇒ `version=0.12.1` و`database=ok`.

## النشر

```bash
# من هذا الدليل — التوكن عبر متغير بيئة فقط (لا يُكتب في أي ملف):
export CLOUDFLARE_API_TOKEN=...   # cfat_... (توكن الحساب — لا يُرفع للمستودع أبدًا)
export CLOUDFLARE_ACCOUNT_ID=758fcc827f3338772847c28391b6c6c3
npx wrangler pages deploy public --project-name=fwms --branch=main
```

## التحقق بعد أي نشر (DEPLOYMENT.md §5)

```bash
curl -s https://fwms-dg8.pages.dev/_gateway/health   # البوابة ذاتها
curl -s https://fwms-dg8.pages.dev/api/health        # التطبيق عبر البوابة — version ≥ 0.9.2 + database:ok
curl -o /dev/null -w "%{http_code}\n" https://fwms-dg8.pages.dev/login   # 200
```
